## 4. 💰 RUMUS BILLING MANAGE SERVICE

```
Tagihan per periode = (Nominal Total SPK ÷ Jangka Waktu) × 1.11
```

### Step

1. Cek nominal total SPK
2. Bagi dengan jangka waktu (bulanan biasanya)
3. Tambah PPN 11% (× 1.11)

### Contoh

- SPK Rp 120 juta untuk 12 bulan
- = Rp 10 juta/bulan
- + PPN 11% = **Rp 11.1 juta tagihan per bulan**

Berlaku untuk Manage Service (Seat Management & Helpdesk).

## 7. 🔄 ALUR DOKUMEN / TAGIHAN

```
USER ──────────► KOMERSIAL
                    │
                    ▼
                OPERASIONAL (saya) ──► USER (TTD)
                    │                       │
                    ▼                       │
                KEUANGAN ◄──────────────────┘
                (setelah semua signed)
```

### 4 Step

1. **User** → Komersial (request)
2. **Komersial** → Operasional (saya / IT)
3. **Operasional** → User (untuk tanda tangan)
4. **Semua signed** → Operasional → **Keuangan** (proses)
