- ✅ **Done** — Selesai
- 🟡 **Draft** — Lagi dibuat
- 🟦 **Review** — Menunggu approval/TTD
- ⏳ **Belum** — Belum dimulai
- ❌ **Blocked** — Ada kendala
- — **N/A** — Tidak berlaku (mis. BAST cuma sekali)

## 🎯 Rekomendasi Format ke Pak Rizky

**Saran ku**: pakai **Format 1 (Excel/Sheets)** untuk monitoring overview, **Format 2 (Markdown/Notion)** untuk detail per project.

Kombinasi paling efektif:
- **Sheets** → quick scan status semua project dalam 1 layar
- **Notion / Doc per project** → detail catatan setiap bulan

Atau kalau Pak Rizky lebih comfort dengan **Excel doang**, gabungkan jadi 1 file Excel dengan:
- Sheet 1: Master Project List
- Sheet 2: Tracking per Project (6 sheet, 1 per project)
- Sheet 3: Summary monthly status

---

## 📅 Update Frequency

- **Tiap selesai bulan** → update checklist project bulan tersebut
- **Tiap Jumat** → review semua, masukin ke laporan mingguan ke Bu Raisa
- **Tiap awal bulan** → setup checklist bulan baru

---

## 📤 Cara Share ke Pak Rizky

1. **Save Google Sheets** → set permission "Anyone with link can view" atau "Edit"
2. Share link ke Pak Rizky via WA
3. Beliau bisa monitor real-time tanpa harus minta update terus

Atau export ke Excel/PDF, kirim per bulan.
